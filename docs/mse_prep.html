MSE with Managers

  • Andre Punt will be leading this course and Kristin Privitera-Johnson will be assisting.
  • Huge thanks to Brett Crisafulli for the following instructions.

To get ready for the “MSE for Managers” class, you will need to install a few programs and packages. This will ensure the interactive course materials run smoothly on your machine.

For those who are unfamiliar with this software, please do not be concerned. You will not be writing any code. You will simply be using interactive apps to explore and demonstrate some of the course concepts.

For context, here is a quick breakdown of what we will be using:

  • R: The underlying statistical programming language that processes the data.
  • RStudio: The application we use to view, organise, and interact with R.
  • Shiny: A tool that turns R code into user-friendly, interactive web apps.

To get set up before the workshop, please follow the steps below.

    • Install the following two programs: R for Windows 4.6.1, and RStudio 2026.07.1
    • They will take about 10 minutes to complete.

    • While the software is installing, download the course materials from the Google Drive link that has been emailed to you. Need the link again? Email us at stockassessmentcop@gmail.com.
    • Click the Download all button in the top right corner to get a ZIP file containing the Examples, Lectures, and References.

    • Once downloaded, you must extract or unzip the folder to a location on your computer.
    • The Shiny apps will not run if they are still inside the ZIP file.

    • To make sure everything is working, open one of the four Shiny apps included in the materials:
      • Navigate to the extracted folder and open Examples > Example 1.
      • Shiny apps consist of a few different files, but you only need to open the ui.R file. Double-click it to open it in RStudio.
      • Once open, RStudio may show a yellow banner across the top asking you to install packages. You can ignore this banner. We are going to install the six required packages all at once.
      • In RStudio, look for the Console window (this is usually the bottom-left panel).
      • Copy the exact line of code below, paste it into that Console window, and press Enter: install.packages(c("MASS", "shiny", "markdown", "bsplus", "RTMB", "mvtnorm"))
      • You will see text scrolling by as the packages download. Wait until it stops and you see the > symbol appear again. This means the installation is finished.
      • For the best viewing experience, we want the app to open in your web browser rather than a small pop-up. Next to the Run App button (located at the top left of the script viewer pane), click the small drop-down arrow and select Run External.
    • Finally, click the Run App button.
    • The app should now fire up in a new window. Once you have made it this far, you are fully good to go for next week.
